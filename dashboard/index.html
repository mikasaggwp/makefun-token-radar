How the value is worked out

implied value = TVL × category multiple × growth × maturity × chains

Growth is the 7-day TVL change, clamped to −50%…+100% (weight 0.6). Maturity grows with how long the protocol has run with no token (0.70–1.00 over 4 years; unknown age counts as 1 year). Chains add 3% each, up to 15%. Sector multiples: curators & allocators 0.40, lending & CDP 0.32, DEXs & perps 0.30, RWA & basis 0.28, yield 0.26, stables / payments / insurance / prediction 0.24, other 0.20, a bare chain 0.15. No name is ever special-cased — the same formula scores every row, from the snapshot's own figures only. An implied value is this entry's claim, not a prediction that a token will be issued, or when.
