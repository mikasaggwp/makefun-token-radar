Token Radar

Every protocol DefiLlama tracks that records no token yet, ranked by what its launch would be worth.

How the value is worked out — fitted, not guessed

implied value = fitted value × token odds  ·  fitted value = exp(acategory + 0.52 × ln TVL) × growth × chains

The line is fitted on this snapshot's own traded-token comparables (log market cap on log TVL, 128 protocols with a positive market cap; a category's intercept is used only when the category has ≥3 comparables, and the shift from the pooled intercept is capped at ±0.5 log — the range guard). Growth is the 7-day TVL change, clamped to −50%…+100% at weight 0.3 — the snapshot's own data says growth barely moves the residual (correlation −0.14), so the weight is small. Chains add 2% each, up to 10%. Token odds are the share of peer protocols in the same age bin that record a token, smoothed toward the overall share. No name is ever special-cased — the same fit scores every row, from the snapshot's own figures only. An implied value is this entry's claim, not a prediction that a token will be issued, or when.

Proof strip — check the claims on this page

Validation is measured inside the run, not asserted: leave-one-out refits the line without each live protocol in turn; walk-forward fits on the oldest 70% of live protocols by listed date and predicts the newest 30%. Both are scored against a flat median market-cap/TVL ratio. Two rival models — one line per category, and a quadratic log-log curve — were fitted blind and tested on the same tests; neither beat the pooled line on leave-one-out by any robust margin, so the pooled line scores the board and the rivals are printed in the proof strip, not hidden. Every row carries a bootstrap band and a rank range over 200 refits of the comparables. Farm $/hr is costed at $100 / $1,000 / $10,000 deposits: expected value assumes a 5% airdrop pool and farmers collectively deploying 10% of TVL, minus gas and opportunity cost at a 5% annual (T-bill) rate — a relative score, never a payout promise. The detail view recomputes each row's fitted value live from the TVL and the fitted line using the row's own category intercept, so the board and the code agree, and its sandbox lets you move the assumptions and watch the row's numbers move.
