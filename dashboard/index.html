How the value is worked out — fitted, not guessed

implied value = fitted value × token odds

The curve is fitted on this snapshot's own traded-token comparables (log market cap on log TVL and log TVL squared, 128 protocols with a positive market cap). Growth is not in the model — the snapshot's own data says growth barely moves the residual (correlation −0.14) and every growth weight tested is worse on all four validation tests. Chains are not in the model either — the two largest tests say a chain bonus hurts. Categories are not in the curve at all; a category only affects a protocol's token odds. Token odds are the share of peer protocols in the same age bin that record a token, blended with the protocol's own category token rate (shrunk toward the age-bin rate). No name is ever special-cased — the same fit scores every row, from the snapshot's own figures only. An implied value is this entry's claim, not a prediction that a token will be issued, or when.

Proof strip — check the claims on this page

Validation is measured inside the run, not asserted: leave-one-out refits the curve without each live protocol in turn; walk-forward fits on the oldest 70% of live protocols by listed date and predicts the newest 30%; two genuinely held-out splits (the newest 20% of dated comparables, and a seeded 80/20 random split) are never seen while fitting. All four are scored against a flat median market-cap/TVL ratio, and four rival models are tested on the same four splits — the plain quadratic wins the four-test average, the walk-forward test and the leave-one-out test, but the pooled line edges it on held-recent by 0.0013 and per-category lines win held-recent outright, so the win is real but not a sweep. Token odds are scored by 5-fold cross-validation over all 758 protocols. Every row carries a bootstrap band and a rank range over 200 refits of the comparables. Farm $/hr is costed at $100 / $1,000 / $10,000 deposits: expected value assumes a 5% airdrop pool and farmers collectively deploying 10% of TVL, minus gas and opportunity cost at a 5% annual (T-bill) rate — a relative score, never a payout promise. 121 of the 594 deposit scenarios can never break even (the launch odds required exceed 100%) and are marked as such. The detail view recomputes each row's fitted value live from the TVL and the fitted quadratic curve, so the board and the code agree, and its sandbox lets you move the assumptions and watch the row's numbers move.
